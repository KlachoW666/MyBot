# RAGEDROP — CS2 Case Opening (demo)

Фронтенд-демо сайта открытия кейсов CS2 в стиле [RAGEDROP](https://www.behance.net/gallery/248071409/CS2-Case-Opening-26-rage-drop): тёмная тема, кейсы с рулеткой, апгрейд предметов, инвентарь и профиль.

Это витрина/прототип: весь баланс и инвентарь виртуальные, хранятся в памяти браузера (баланс) и `localStorage` (кейсы, созданные через админку). Бэкенда, реальных ставок и реальных выплат нет.

## Стек

- React + TypeScript + Vite
- React Router
- Tailwind CSS v4
- Framer Motion (анимация рулетки/апгрейда)

## Запуск

```bash
npm install
npm run dev
```

## Структура

- `src/pages` — страницы: главная, открытие кейса, апгрейд, профиль, админ-панель
- `src/components` — переиспользуемые UI-компоненты (карточки предметов/кейсов, рулетка, навигация)
- `src/store` — глобальное состояние: баланс/инвентарь (`StoreContext`) и кейсы/каталог предметов (`CasesContext`, персистится в `localStorage`)
- `src/data` — базовые данные (предметы, кейсы, редкости)
- `src/utils` — логика рулетки (взвешенный рандом) и расчёта редкости при апгрейде

## Экономика дропа

У каждого кейса зафиксированы веса вероятности по предметам (честный fixed-odds house edge, без слежки за тратами конкретного игрока). Проценты шанса на каждый предмет показаны прямо в интерфейсе кейса.

## Админ-панель

`/admin` — создание кейсов, добавление предметов в пул с указанием веса, просмотр процентов выпадения и мгновенный тест открытия кейса. Данные сохраняются в `localStorage` браузера.
