# Russia Oil — карта наличия топлива

Нативное Android-приложение (Kotlin + Jetpack Compose) — краудсорсинговая карта
наличия топлива на АЗС. Пользователи отмечают прямо на карте, есть ли на заправке
бензин, газ или дизель и по какой цене; остальные видят актуальный статус.

**Техподдержка и Telegram-канал:** [@oilfor](https://t.me/oilfor)

Карта — **Yandex MapKit**. Все данные (пользователи, АЗС, регионы, отметки) хранятся
локально в **SQLite (Room)** — приложение самодостаточно и работает офлайн, без
внешнего бэкенда.

> Это рабочая тестовая версия (MVP). Сборка APK выполняется автоматически в GitHub
> Actions, готовый файл публикуется в **Releases**.

## Возможности

- **Регистрация и вход**: логин, пароль (PBKDF2-хеш + соль), почта, госномер с регионом.
  Сессия сохраняется между запусками. Восстановление пароля по логину+почте.
- **Карта Yandex MapKit** с маркерами АЗС и цветовой индикацией по свежести данных:
  - 🟢 топливо есть, отметка свежая (< 2 ч)
  - 🟡 данные устаревают (2–6 ч)
  - ⚪ данных нет / отметка старше 6 ч
  - 🔴 отмечено, что топлива нет
- **Отметка наличия**: типы (АИ-92/95/98/100, газ, дизель — мультивыбор), наличие,
  цена за литр, индикатор очереди. Время отметки проставляется автоматически.
  Один актуальный статус на АЗС + полная история.
- **Регионы**: Московская область, Краснодарский край, Волгоградская, Ростовская,
  Крым, ДНР, ЛНР. Метки вне активного региона блокируются сообщением
  «Регион пока не поддерживается».
- **Защита геолокацией**: при сохранении отметки приложение проверяет фактическое
  местоположение пользователя — отметку можно поставить только находясь рядом с АЗС
  (≤ 750 м). Это не даёт ставить ложные метки «из другого города».
- **Доверие к данным**: подтверждения «Подтверждаю» / «Закончилось», карма,
  таблица лидеров по региону.
- **Фильтр карты** по типу топлива.
- **Админка** (роль admin/super-admin): список и поиск пользователей, профиль и история
  меток, включение/выключение регионов, добавление АЗС, модерация (удаление меток,
  бан/разбан), назначение/снятие роли администратора.

## Вшитый супер-администратор

При первом запуске создаётся аккаунт супер-администратора:

- **Логин:** `sputnik`
- **Пароль:** задан в коде сидинга (`DatabaseSeeder`), роль `SUPER_ADMIN`.

Супер-администратора нельзя забанить или понизить. Только он может назначать/снимать
роль обычных администраторов.

## Архитектура

- Kotlin + Jetpack Compose (Material 3), MVVM, репозитории, Coroutines/Flow.
- Room (SQLite), DataStore (сессия), ручной DI-контейнер (`AppContainer`).
- Yandex MapKit `com.yandex.android:maps.mobile` (Maven Central).
- `minSdk 26` (Android 8.0+, требование Yandex MapKit), `compileSdk 35`, `targetSdk 34`.

```
app/src/main/java/com/fuelmap/app/
  data/local/        # Room: сущности, DAO, БД, сидинг
  data/security/     # PBKDF2 хеширование паролей
  data/session/      # DataStore-сессия
  data/repository/   # Auth/Station/Mark/Admin
  domain/model/      # enum FuelType, Role, MarkFreshness …
  ui/                # Compose-экраны + ViewModel (auth, map, station, admin, …)
```

## Сборка APK

### Автоматически (GitHub Actions) — рекомендуется

Каждый push в ветку сборки запускает workflow `.github/workflows/android-build.yml`,
который собирает debug-APK и публикует его:

- в **Releases** (тег `build-<номер>`),
- как **artifact** на странице запуска в Actions.

Скачайте `RussiaOil-debug-*.apk`, включите на телефоне установку из неизвестных
источников и установите (Android 8.0+).

### Локально

```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Требуется установленный Android SDK (platform 34, build-tools 34.0.0) и JDK 17.

## Ключ Yandex MapKit

Ключ MapKit для Android встраивается в APK (ограничен по package приложения — это
штатно). Текущий ключ задан как значение по умолчанию в `app/build.gradle.kts`.

Переопределить можно любым из способов:

- свойство Gradle: `./gradlew assembleDebug -PmapkitApiKey=ВАШ_КЛЮЧ`
- переменная окружения `MAPKIT_API_KEY`
- секрет репозитория **`YANDEX_MAPKIT_API_KEY`** (его подхватывает CI)

Получить ключ: Yandex Developer Console → MapKit SDK.
